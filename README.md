# BrandCore Indonesia — Official Website

Website company profile BrandCore Indonesia, terpisah dari aplikasi CorePR.

## Stack
- Next.js 15 App Router
- React 19
- TypeScript
- CSS custom responsive

## Local development
```bash
npm install
npm run dev
```

## Deployment target
- Website: https://brandcore.id
- CorePR application: https://apps.brandcore.id

## Before production launch
1. Confirm official company address, email, telephone, office hours, legal entity details and leadership.
2. Replace placeholder portfolio/team information with approved content.
3. Configure a real contact form endpoint and spam protection.
4. Review legal pages with qualified counsel and align them with actual data practices.
5. Configure analytics and cookie consent only after selecting vendors and purposes.
6. Confirm hosting plan permits commercial use.

The contact form is intentionally not connected yet; it does not collect or transmit visitor data.
